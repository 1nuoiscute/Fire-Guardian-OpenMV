# Fire Guardian：OpenMV 实验室火情预警原型

Fire Guardian 是一个面向嵌入式视觉入门的火情预警原型。它结合 OpenMV 图像识别、温度阈值、蜂鸣器/LED 告警、OLED 显示和 ESP8266 通信，探索“小型边缘设备如何发现异常并通知用户”。

> 这是课程/竞赛原型，不应替代任何专业消防设备。请勿将其用于真实安全关键场景。

## 功能概览

- 基于颜色阈值、面积和形状特征检测疑似火焰。
- 结合温度条件，降低单一视觉判断带来的误报。
- 通过 OLED、LED 和蜂鸣器输出本地告警。
- 通过 ESP8266 提供局域网通信；v2 还支持可选的联网通知。
- 提供 Flutter 配套应用的实验性实现。

## 快速开始

1. 使用 OpenMV IDE 打开 `v1/main.py`。
2. 根据实际模块修改顶部的引脚、颜色阈值和温度阈值。
3. 先断开 ESP8266，只验证相机、OLED、LED 和蜂鸣器。
4. 通过串口逐步加入网络功能。

## 联网配置

本项目仅用于学习嵌入式视觉、串口通信和多传感器告警逻辑；其检测结果不能作为火灾处置依据。
